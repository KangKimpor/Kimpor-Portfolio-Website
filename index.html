04 // Engineering Utilities

Engineering Utilities & Workflow Automation.

Small internal tools built to take a repetitive step off the team. These are personal side builds, not a software engineering practice.

Utility // App Build Active in Production

SB Grab Code Tracker

Ride-code allocation · React & Firebase

Staff collect their own ride codes instead of sending every request through one person. I found the bottleneck at work, then designed and shipped the fix: a live board of available codes with a simple claim step.

The friction

Every request queued behind one person, who also had to track which codes were still free.

The impact

Staff self-serve from the board. One person is no longer the queue, and code availability is visible to everyone.

  • React
  • Firebase
  • Vercel
  • Role-based access
Utility // Bot Pipeline Active in Production

Manpower Reporting Automation

Telegram → Google Sheets · Google Apps Script

// Telegram webhook · NBC site group

> "NBC: 12 carpenters, 6 MEP, 4 painters"

>> parsed [CARP: 12] [MEP: 6] [PNT: 4]

>> 22 rows appended to NBC_Manpower_2025

Supervisors post the daily headcount into a Telegram group in plain text. The bot parses each trade, writes the row into a central Google Sheet, and keeps the manpower curve current without a second data entry pass.

The friction

Collating fragmented chat messages into the monthly labour report cost roughly 45 minutes at the end of every site day.

The impact

Headcount per trade is captured the day it happens, so monthly labour reporting became a refresh instead of a rebuild.

  • Telegram Bot API
  • Google Apps Script
  • Google Sheets
  • Regex parsing
