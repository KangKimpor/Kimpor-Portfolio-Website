04 // Tools

Tools That Speed Up Repetitive Tasks.

Small tools I built to take repetitive work off the team.

Tool // App In Daily Use

SB Grab Code Tracker

Ride-code allocation · React & Firebase

Staff used to send every ride-code request through one person. I built a live board where they can see free codes and claim one themselves.

The friction

Every request waited on one person, who also had to track which codes were free.

The impact

Staff help themselves from the board, and everyone can see which codes are free.

  • React
  • Firebase
  • Vercel
  • Role-based access
Tool // Bot In Daily Use

Manpower Reporting Automation

Telegram → Google Sheets · Google Apps Script

// Telegram webhook · NBC site group

> "NBC: 12 carpenters, 6 MEP, 4 painters"

>> parsed [CARP: 12] [MEP: 6] [PNT: 4]

>> 22 rows appended to NBC_Manpower_2025

Supervisors post the daily headcount in a Telegram group. The bot reads each trade, writes it into a shared Google Sheet, and keeps the manpower records up to date.

The friction

Collecting scattered chat messages for the monthly labour report took about 45 minutes at the end of every site day.

The impact

Headcount per trade is saved the same day, so the monthly labour report is ready right away.

  • Telegram Bot API
  • Google Apps Script
  • Google Sheets
  • Regex parsing
